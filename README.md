## What I build for myself

All of this runs on a homelab I maintain — a Proxmox host with containerised
services, ZFS storage, and a GPU doing inference work.

- 🖼️ **A self-hosted image and video generation app** — React + Hono + SQLite.
  Multi-user with per-account isolation, a content-safety pipeline built on local
  LLM sidecars, a community feed, and an API-key surface other clients build
  against.
- 🤖 **A Discord bot** driving that app through the same public API surface —
  deliberately a thin client, no privileged access.
- ⚡ **GPU inference tuning** on Intel Arc — quantised diffusion models, PyTorch
  XPU, and a fair amount of carefully measuring things that turned out not to help.
- 🛠️ **The infrastructure underneath** — Proxmox, LXC, ZFS, Cloudflare Tunnel,
  CrowdSec, monitoring, and backups I actually restore-test.

These are private for now; some may open up.
